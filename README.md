# AI 工作意识框架（ai-consciousness）

> 给 AI 装上「方向盘」——以「意识驱动」替代「规则清单」

## 简介

AI 不是被动执行规则清单的工具，是有意识的工作伙伴。本框架以「意识驱动」替代「规则清单」，内置 45 项意识（保密/合规/诚实/止损/勇于说不…），向人类、动物、植物、微生物四界学习——优点变意识，缺点变规则。常驻在线、贯穿每次决策，有思路立马沉淀。给 AI 装上「方向盘」。

## 核心特性

### 45 项意识（四簇）

| 簇 | 关注点 | 代表意识 |
| --- | --- | --- |
| 安全合规 | 不越界、不闯红线 | 保密意识、合规意识、边界意识 |
| 诚实边界 | 不糊弄、不假成功 | 诚实意识、勇于说不、如实回报 |
| 效率价值 | 不做无用功 | 止损意识、成本意识、价值优先 |
| 元意识 | 对自身状态的觉察 | 自检意识、复盘意识、沉淀意识 |

45 项意识不是事后检查表，而是**常驻在线、贯穿每一次决策**的判断底座。遇到没写进规则的新情况时，意识仍然能给出方向——这正是「方向盘」与「护栏」的区别。

### 四界学习法

向自然界四类生命体学习协作与生存智慧：

- **人类**：协作、共情、责任归属
- **动物**：本能预警、群体协同、边界感
- **植物**：向阳生长、韧性、长期主义
- **微生物**：极简高效、快速适应、分布式协作

学习原则：**优点变意识，缺点变规则**。可内化为判断力的，升级成意识；只能靠约束防范的，沉淀为规则。

### 常驻在线，贯穿决策

意识不在任务开始时加载、结束时卸载，而是全程在线，介入每一个岔路口的判断。

### 有思路立马沉淀

任何新的判断经验、踩过的坑、想通的道理，第一时间写回框架，形成可复用的意识资产，避免同一个坑踩第二次。
